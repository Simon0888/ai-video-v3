## 3. 已实现的原型功能

| 环节 | 已实现 | 当前边界 |
| --- | --- | --- |
| 选品 | 示例商品、分类、搜索；添加自定义商品、价格、佣金、卖点及人群 | 示例数据，不连接电商商品库 |
| 对标视频 | 记录分享链接；本地 MP4 / MOV / WebM 导入、预览与原文件下载；示例结构 | 平台链接仅记录，不抓取或下载；文件最大 100 MB |
| AI拆解 | 按商品卖点和观察备注生成内容结构建议 | 演示模板，未识别实际视频内容 |
| 脚本重构 | 平台、风格、15 / 30 / 60 秒配置；分段口播编辑 | 演示模板，未调用大模型 |
| 分镜 | 镜头清单、画面描述与字幕编辑 | 文字分镜，不生成 AI图片或视频画面 |
| 成片 / 导出 | 创建制作任务；导出 TXT、CSV、JSON；浏览器生成 WebM 文字分镜预览片 | 无商品实拍、配音、音乐或正式 MP4成片；WebM实际录制与播放尚未浏览器验收 |

更换商品、素材或修改脚本等上游数据会使后续制作资料失效，避免继续使用过时内容。草稿仅保存在当前浏览器的 `localStorage`，键为 `zaopian-v1`。本地原视频和生成的 WebM 只保留在当前页面会话，刷新后需重新选择或生成。

没有业务后端、用户账号体系、数据库、跨设备草稿同步、外部 AI服务或已保存的 API密钥。站点私有访问由托管平台提供，不等于已实现应用账号体系。不要对用户承诺已实现真实 AI生产链路。

## 6. 验证事实与待验收项

第一版源码已通过 JavaScript 语法检查、静态构建，以及 **12 项自动逻辑检查**，包括：

1. 六步资料与任务关联。
2. 换商品后清除旧的下游结果。
3. 改脚本后清除分镜与任务，重新生成时使用修改内容。
4. 改镜头后清除旧任务并保留修改。
5. 15 秒设置同步到分镜时间轴。
6. 浏览器草稿数据恢复。
7. 无效链接不污染当前参考素材。
8. 分享文本中的有效链接仅记录，不冒充已下载。
9. 自定义商品添加与选择。
10. TXT、CSV、JSON 导出动作及文件名。
11. WebMCP导航参数验证与共享状态。
12. 不可信商品文本的 HTML转义。

这些检查使用离线 DOM 替身，不覆盖真实浏览器布局、上传、录制、编解码、播放、下载文件内容或 WebMCP浏览器上下文；不得把它们写成完整端到端验收通过。

浏览器验收曾被应用的权限校验阻止：工具无法核实保存的浏览器访问权限。因此手机 / 桌面视觉、键盘操作、本地视频上传、WebM生成与播放、真正的文件下载仍待验收。网页打开请求返回的是 `queued`，没有确认用户已经看到页面。新窗口可以在当前正常权限下重试；不要绕过浏览器安全检查。

建议下一步先执行一次真实完整操作链：选择商品 → 使用示例结构 → 生成演示拆解 → 设为 15 秒 → 生成并编辑脚本 → 生成并编辑分镜 → 创建任务 → 导出资料 → 生成、播放并下载 WebM → 刷新检查草稿 → 切换商品检查旧结果失效。另检查无效链接、不可播放或超限视频、窄屏和键盘操作。
