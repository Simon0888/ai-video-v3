# V0.3 网页版接入与验收

用户要求：更换电脑后登录浏览器继续使用；只同步商品、脚本、分镜、项目进度与台词文字；全部视频处理在浏览器内进行，素材不上传。继续原 Simon0888/ai-video-v3 和 owner-private Site，不创建新站点。

## 实现

- 原 Site 增加 Worker 和 D1 文字库，保留 project_id；r2 为 null。
- 数据白名单只接受限定长度文字与元数据，不接收 Blob、原文件、帧图、MP4、音频、data / blob URL、未知字段或大请求。保存使用版本比较；冲突显示版本选择，首次先读取账号资料，不用空草稿覆盖现有项目。
- 网页不再访问 127.0.0.1:4173。视频选择、指纹、抽帧、概览、画面变化候选在浏览器进行；同文件重新关联保留编辑结果。
- Whisper tiny q8 / Transformers.js 在 Web Worker 内实际识别 16 kHz 单声道 PCM。工具和公开模型为下载流量，没有素材上传。
- FFmpeg WASM 在浏览器合成带校正字幕的原片 MP4，保留画面、声音和画幅。Noto CJK 字体来自公开发行版。原始转写独立保留；校正不冒充重新对齐时间。
- WebM 文字分镜预览仍在浏览器生成。断网草稿留在当前浏览器，素材和生成片只在页面会话中。
- 取消任务会释放浏览器处理线程，旧任务不会覆盖后续任务。Hypit 原生 CLI 没有在网页中运行；旧本机源码保留作研发历史。

## 限制

浏览器语音模型更轻，准确度有限；画面变化候选按秒采样。原文件必须自行保留，换电脑重新选择，视频导出重新生成。首次下载受网络速度影响，长视频消耗时间和内存，请保持页面打开。原型沿用一个当前项目，创建新项目前可以导出资料。

平台视频抓取、真实视觉语义拆解、AI脚本生成、画面 / 视频生成、配音和新商品正式广告成片仍未接入。字幕校对 MP4 与文字 WebM 是已实现的基础导出，不等同于正式 AI成片。
