# 造片 · 短视频带货生产工作台

业务流程：**选品 → 导入对标视频 → 拆解 → 脚本重构 → 分镜生成 → 成片任务 / 导出**。

当前为 V0.2：原型工作流加本机视频基础处理。原私有站点继续使用 [造片工作台](https://ai-video-v3-simon-workbench.simon000888.chatgpt.site)，访问范围保持账号本人。

## 这台电脑直接使用

双击桌面 **「启动造片本机版」**，打开 <http://127.0.0.1:4173>。

也可以打开原私有站点，点击「连接本机处理」。处理期间电脑和本机服务需要运行。浏览器如询问本地网络访问，按正常权限允许该工作台连接；若浏览器不支持此连接，可直接使用本机版。手机或其他电脑不能使用本机回环地址访问这台电脑的处理服务。

本地视频、处理记录、帧图、字幕和 MP4 存放于当前仓库的 .local/jobs/，不上传到 Site 或 GitHub。处理记录可在刷新和服务重启后恢复；未提交本机处理的原文件预览和 WebM 预览片仍只在当前页面会话中有效。草稿保存在当前浏览器 localStorage，不跨设备同步。

## 从仓库恢复

普通原型页面需要 Node.js 20+，无需依赖：

~~~sh
node server.mjs
node --test tests/*.test.mjs
node build.mjs
~~~

完整本机处理另需 **Node.js 22.15+、Windows x64、Python 3.12**。Hypit、Python 依赖和模型需要单独准备：

~~~powershell
.\tools\setup-local.ps1
.\tools\create-desktop-shortcut.ps1
node tools/start-local.mjs
~~~

首次准备会从官方 npm、PyPI、Gyan FFmpeg 和 Hugging Face 获取工具与模型；已有完整语音模型缓存会直接复用。不会修改系统 PATH，不设置开机自启，不保存外部服务 API 密钥。工具存放在 %LOCALAPPDATA%\Zaopian，本机路径配置存放于忽略的 .local/engine.json。

本次已锁定 Windows 验证通过的版本。转写使用 FFmpeg 生成的 16 kHz 单声道 PCM，避开 PyAV 新版解码接口兼容问题。当前采用 CPU int8，无需显卡或付费服务。真实拆解限制：5 分钟以内、长边不超过 4096 像素、最大 100 MB。

## 实现与部署

- app.js：六步流程、演示模板、草稿、分镜资料与 WebM。
- engine-client.js / engine-ui.js：连接本机、真实证据、台词校正、字幕与 MP4。
- server.mjs / engine/：回环服务、任务队列、Hypit 媒体工具、语音识别和 FFmpeg 合成。
- runtime/：锁定的工具与 Python 依赖清单；依赖文件与本地媒体不提交。
- tools/：安装、桌面启动和真实视频验收入口。
- .openai/hosting.json：现有 Site 关联，保持原项目与账号私有访问。

构建只复制 5 个前端文件到 dist/。Site 部署只包含前端与托管配置，云端不运行原生 FFmpeg / Python；本机处理需要上述回环服务。API 限制来源为本机页面和原私有 Site，拒绝其他来源与 DNS 重绑定 Host，使用仅在内存中的会话令牌；本机路径、模型、素材和密钥不通过静态服务器公开。
