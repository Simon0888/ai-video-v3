# 造片 · 短视频带货生产工作台

第一版业务原型，流程为：**选品 → 导入对标视频 → AI拆解 → 脚本重构 → 分镜生成 → 成片任务 / 导出**。

## 本地运行

需要 Node.js 20 或更新版本，无需安装依赖。

```sh
node server.mjs
# 打开 http://127.0.0.1:4173
node --test tests/workflow.test.mjs
node build.mjs
```

构建输出为 `dist/`，可部署到静态网站托管。Sites 部署关联保存在 `.openai/hosting.json`。

## 可以体验的功能

- 示例商品筛选、搜索；添加自己的商品、售价、佣金、卖点和目标人群。
- 本地 MP4 / MOV / WebM 视频导入、预览与原文件下载，最大 100 MB。
- 保存平台分享链接、使用示例内容结构；无效链接显示错误提示。
- 基于商品信息与观察备注生成演示拆解、演示脚本；调整平台、风格和目标时长。
- 编辑口播、画面描述和字幕；自动保存此浏览器草稿。
- 修改上游数据时使下游资料失效，避免导出过时的脚本或分镜。
- 创建制作任务，导出 TXT 口播、CSV 分镜和 JSON 项目资料。
- 浏览器通过 Canvas / MediaRecorder 生成真实的 720×1280 WebM **文字分镜预览片**，可播放和下载。预览片无真实商品画面、配音或背景音乐。

## 原型边界

AI分析与脚本建议是演示模板，未接入视频识别或大模型。链接仅记录，不抓取平台视频。商品示例数据不来自电商平台。正式 AI画面生成、配音、MP4 成片、账号与跨设备同步尚未接入。

草稿保存在当前浏览器的 localStorage；本地原视频和生成的视频只在当前页面会话内可用，刷新后需重新选择或生成。文件不上传到服务器。价格、卖点及效果需按商品实际信息核对。

## 验收

`tests/workflow.test.mjs` 检查六步状态流转、上游变更导致下游失效、草稿恢复、链接验证、自定义商品、导出触发、文本转义和 WebMCP 参数校验。它使用离线 DOM 替身，**不代表浏览器视觉、视频编解码或播放验收**。

浏览器人工验收建议：选择商品 → 使用示例结构 → 生成演示拆解 → 设置 15 秒 → 生成并编辑脚本 → 生成分镜 → 创建任务 → 导出资料 → 生成预览片并播放、下载 → 刷新检查草稿 → 切换商品检查下游重置。另检查手机宽度布局、键盘操作、本地视频上传和无效链接提示。
