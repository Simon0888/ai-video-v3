# 造片 · 短视频带货生产工作台

业务流程：**选品 → 导入对标视频 → 拆解 → 脚本重构 → 分镜 → 成片任务 / 导出**。

V0.3 改为网页版使用。打开 [原私有工作台](https://ai-video-v3-simon-workbench.simon000888.chatgpt.site)，登录同一个账号即可继续项目，普通使用无需安装 Node、Python、Hypit 或启动本机服务。访问仍只允许账号本人。

## 换电脑继续使用

商品信息、参考链接、台词文字与校正、脚本、分镜、设置和项目进度保存在原 Site 的 D1 数据库。浏览器保留一份本地草稿应对断网。首次读取账号资料后才允许同步，避免新电脑的空草稿覆盖已保存项目；两台设备同时修改时显示版本选择，不静默覆盖。

**视频、图片、音频、抽取帧图和生成视频不上传、不保存在云端，也不提交 GitHub。** 网页没有素材接收接口和 R2 绑定。素材通过浏览器文件选择、Canvas 和 WebAssembly 处理；处理工具、语音模型、字体只从公开来源下载到当前电脑。

换电脑或刷新页面后，脚本和分镜可以继续编辑。需要预览原视频、查看帧图或合成字幕 MP4 时，请重新选择同一个原文件：SHA-256 指纹一致时恢复关联，保留已有文字修改；选择不同文件会建立新的对标资料并使后续内容失效。原文件需要自行保留或带到新电脑。WebM 和 MP4 需重新生成。

等待「项目文字已随账号保存」后再离开。断网或保存失败会提示并保留当前浏览器草稿；恢复网络后重试。每次可保存 512 KiB 项目文字，目前沿用一个当前项目的原型结构，新建项目会替换它，建议先导出需要保留的资料。

## 实际能力与演示边界

| 能力 | 当前状态 |
| --- | --- |
| 添加商品、设置价格卖点、筛选搜索 | 实际可用；示例商品未连接电商平台 |
| 导入、预览和下载本地 MP4 / MOV / WebM | 实际可用，最大 100 MB，编码需浏览器支持 |
| 分享链接抓取 / 平台视频下载 | 仅记录链接，尚未接入 |
| 视频信息、8 张关键帧、12 帧概览 | 浏览器实际读取与抽帧 |
| 切点候选 | 每秒采样的画面变化候选，有粗略误差，不是语义分镜 |
| 中文台词与时间识别 | Transformers.js / Whisper tiny q8，在浏览器内实际运行；准确度有限，需要人工校正 |
| 校正台词、SRT、原始与校正 JSON | 实际可用，原始文字独立保留，修改文字不宣称重新对齐时间 |
| 故事结构判断、商品卖点推断、AI脚本改写 | 仍为演示模板；可导入实际台词后人工重构 |
| 分镜编辑、TXT / CSV / JSON 下载 | 实际可用，随账号保存文字 |
| 文字分镜 WebM 预览 | 浏览器实际生成，720×1280，无商品实拍、配音与音乐 |
| 原片字幕校对 MP4 | 浏览器 FFmpeg WASM 实际合成，保留原画面、声音和画幅，叠加校正字幕 |
| AI画面、视频生成、配音、新商品正式广告成片 | 尚未接入，未调用付费模型 |

原片已经烧录的字幕会保留。字幕校对 MP4 不是替换人物、商品或配音后的广告成片。浏览器拆解限 5 分钟、长边 4096 像素、100 MB。首次工具约 31 MB，加上语音模型和字幕字体需要下载；浏览器缓存可能被系统清理。请保持页面打开，较长或高分辨率视频更慢、占用更多内存；弱设备可先导出文字资料。

## Hypit 的接入关系

V0.2 曾通过本机 Hypit 0.3.0、faster-whisper small 和原生 FFmpeg 完成基础媒体处理。按照用户「全部浏览器处理，不上传素材」的要求，V0.3 保留拆解证据、校正、脚本与导出流程，执行工具换为浏览器 Canvas、Transformers.js 和 FFmpeg WASM。**Hypit 的原生 CLI 没有在浏览器运行。** 不把 Codex skill 本身当成网页服务或自动接入的付费 AI。

原 engine/、runtime/ 和安装脚本保留作历史研发对照；旧桌面「启动造片本机版」不是当前网页的必要条件或推荐入口。历史验收说明见 [V0.2 记录](docs/HYPIT-INTEGRATION-2026-10-09.md)。

## 开发与部署

普通使用只需浏览器。开发、测试和本地 SQLite 预览需 Node.js 24+、pnpm，安装仓库锁定依赖后运行：

~~~sh
pnpm install --frozen-lockfile
node --test tests/*.test.mjs
node build.mjs
node tools/web-preview.mjs
~~~

预览地址 http://127.0.0.1:4174；本地数据库 .local/web-preview.sqlite 只模拟原账号私有 Site 的文字库，不是真正的线上账号登录。localhost:4174 和 127.0.0.1:4174 可用于独立浏览器存储的恢复验收。

db/schema.ts 为数据库结构，drizzle/ 保留已生成迁移。结构变更先生成并审查迁移，再构建；线上请求不创建或修改表。

build.mjs 生成 Cloudflare Worker dist/server/index.js，将前端文字资源打包为只读路由，并复制 .openai/hosting.json、数据库迁移。云端 Worker 只保存项目文字，不运行 FFmpeg、Python、语音或视频模型。.openai/hosting.json 保留原 project_id，绑定 d1: DB、r2: null；发布继续使用原 owner-private Site。

此工作空间 API 依赖原站点的平台私有访问边界。**不得直接改为公开或多人共享**；如以后需要团队协作，应先实现独立工作空间授权。平台服务凭据只能用于指定 Site 的运维验证，不代表登录用户身份，不进入浏览器、源码或输出文件。

## 验收

30 项自动检查通过，包含原 25 项检查及新增的账号文字恢复、并发版本冲突、拒收素材 / 非法字段 / 大请求和跨来源保存检查。实际浏览器已验证 20 秒有声视频的抽帧、12 段识别、人工校正、SRT / JSON 下载、字幕 MP4 生成 / 完整播放 / 下载，以及独立浏览器草稿环境恢复修改后的脚本、分镜和任务。识别存在明显误差，不能当作已准确理解原视频。
